# Spirit Battle (Roblox)

Prodigy-style spirit battle game. The place file is `Place1.rbxl`, which lives in
`OneDrive\Documents\ChatGPT\Roblox team\work\` and is edited in Roblox Studio.

## src/
Every script in Place1, exported from the open Studio session on 2026-10-22.
The folder layout mirrors the game tree. File names follow the Rojo convention:

- `Name.server.luau` = Script
- `Name.client.luau` = LocalScript
- `Name.luau` = ModuleScript

These files are a tracked copy. Studio is still the live source until a sync
tool (such as Rojo) is set up, so re-export after editing in Studio.
